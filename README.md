# 🎒 صيدلية أسامة عطا الله — عروض العودة للمدارس
### Osama Atta Allah Pharmacy — Back to School Seasonal Campaign Landing Page

صفحة هبوط تسويقية تفاعلية متكاملة، جاهزة للإنتاج (Production-Ready) ومخصصة بالكامل للغة العربية (RTL-First)، مصممة لزيادة معدلات التحويل والمبيعات (CRO-Optimized) لصالح **صيدلية أسامة عطا الله** بمناسبة حملة **"العودة للمدارس"**.

---

## 🌟 نظرة عامة على المشروع (Project Overview)

تهدف صفحة الهبوط إلى تقديم تجربة تسوق سهلة وسريعة للأمهات وأولياء الأمور لتجهيز احتياجات أطفالهم للمدرسة في مكان واحد:
- **كتالوج متكامل لـ 26 منتجاً معتمداً** من مجلة عروض الصيدلية الرسمية (فيتامينات ومناعة، لانش بوكس وعناية بالأسنان، منتجات نظافة يومية، وعناية بالبشرة للأسرة).
- **أسعار مطابقة 100% لمجلة العروض الرسمية** مع توضيح الأسعار القديمة ونسب الخصم الحقيقية.
- **مسار طلب سلس ومباشر عبر واتساب (Frictionless WhatsApp Ordering)** دون الحاجة إلى تسجيل حسابات معقدة أو بوابات دفع إلكتروني غير مألوفة، مع دعم الدفع عند الاستلام.
- **تصميم متجاوب بالكامل (Mobile-First)** مع شريط سلة سفلي ذكي وسلة جانبية منزلقة (RTL Slide-over Drawer).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite 6](https://vitejs.dev/)
- **Styling:** [Tailwind CSS 3](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** خط **Alexandria** العربي المتطور عبر Google Fonts
- **State Management:** React Context API مع دعم التخزين المحلي (LocalStorage) لحفظ السلة

## 🚀 كيفية التثبيت والتشغيل محلياً (Installation & Local Development)

### 1. المتطلبات المسبقة:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- تثبيت `npm` أو `yarn` أو `pnpm`

### 2. تثبيت الحزم:
```bash
npm install
```

### 3. تشغيل بيئة التطوير المحلية:
```bash
npm run dev
```
سيفتح الموقع محلياً على: `http://localhost:5173`

---

## 📦 بناء نسخة الإنتاج والمعاينة (Production Build)

### 1. إنشاء حزمة الإنتاج:
```bash
npm run build
```
يقوم هذا الأمر بفحص كود TypeScript وبناء الأصول المضغوطة داخل مجلد `dist/`.

### 2. معاينة نسخة الإنتاج محلياً:
```bash
npm run preview
```
سيتم تشغيل سيرفر المعاينة السريع على: `http://localhost:3000`

## 📲 آلية إتمام الطلب عبر واتساب (WhatsApp Ordering Flow)

1. **اختيار المنتجات:** يتصفح العميل المنتجات أو يستخدم شبكة Bento أو قائمة الأم التفاعلية (`قبل ما الجرس يرن 🔔`).
2. **الإضافة إلى السلة:** بنقرة واحدة على زر "ضيفيه للطلب"، يتحول الزر تلقائياً إلى عداد كمية تفاعلي `[-] 1 في طلبك [+]` ويتم تحديث أيقونة السلة وإجمالي الحساب فورياً.
3. **مراجعة السلة:** يفتح العميل السلة الجانبية (RTL Cart Drawer) لمراجعة المنتجات والكميات وقيمة التوفير الإجمالية.
4. **التحويل للواتساب:** عند الضغط على زر **"أكمل الطلب على واتساب"**، يتم تلقائياً إنشاء رسالة عربية منسقة تتضمن:
   - قائمة المنتجات المطلوبة وأعدادها وأسعارها
   - إجمالي الفاتورة وقيمة الخصم
   - حقول فارغة لتسجيل الاسم والعنوان للتوصيل
   - إرسال مباشر لرقم الصيدلية المعتمد: `01064646463` (`+201064646463`)
